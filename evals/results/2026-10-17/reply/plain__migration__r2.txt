백필(backfill)은 이미 있는 행에 새 컬럼의 값을 채우는 작업입니다. 20GB 테이블에 NOT NULL 컬럼을 한 번에 추가하면 DB가 모든 행을 다시 쓰고 테이블을 잠글 수 있습니다. 그 사이 다른 쿼리가 대기하기 때문에 마이그레이션이 멈춘 것처럼 보입니다. DB 종류와 버전에 따라 동작이 다릅니다. 예를 들어 PostgreSQL 11 이상은 상수 기본값을 바로 추가합니다.

작업을 여섯 단계로 나누면 됩니다.

1. 멈춘 마이그레이션을 취소합니다. 잠금을 쥔 세션이 남아 있으면 DBA와 함께 종료해야 합니다.
2. NULL을 허용하는 컬럼을 기본값 없이 추가합니다. 이 작업은 메타데이터만 바꾸므로 빠릅니다.
3. 새 행이 값을 갖도록 애플리케이션 코드나 기본값을 배포합니다.
4. 기존 행을 배치로 채웁니다. 한 번에 1만 행 안팎으로 나누고, 배치 사이에 짧게 쉬어야 합니다.
5. NULL이 남지 않았는지 확인합니다.
6. NOT NULL 제약을 겁니다.

4단계의 배치 쿼리 예시입니다. 테이블, 컬럼, 값은 가상의 이름입니다. 기본 키 `id` 범위를 옮겨 가며 반복하세요.

```sql
UPDATE orders SET status = 'unknown'
WHERE id BETWEEN 1 AND 10000 AND status IS NULL;
```

6단계를 PostgreSQL에서 하면 테이블 전체 스캔 중에도 쓰기가 막히지 않습니다. 먼저 검증 없이 제약을 추가하고, 따로 검증한 뒤 NOT NULL로 바꿉니다.

```sql
ALTER TABLE orders ADD CONSTRAINT status_nn CHECK (status IS NOT NULL) NOT VALID;
ALTER TABLE orders VALIDATE CONSTRAINT status_nn;
ALTER TABLE orders ALTER COLUMN status SET NOT NULL;
```

MySQL이라면 `gh-ost`나 `pt-online-schema-change` 같은 온라인 스키마 변경 도구를 DBA와 상의해야 합니다. 사용하는 DB와 버전을 알려 주시면 그에 맞는 명령으로 다시 정리하겠습니다.
