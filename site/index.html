SimpleKorean은 AI가 문서와 답변을 쉬운 한국어로 쓰도록 돕는 에이전트 스킬입니다.
긴 문장을 나누고, 번역투를 줄이고, 용어 표기를 맞춥니다.

02 측정 결과

스킬을 켜면 이렇게 달라집니다

측정에 쓴 원본 출력을 공개합니다. 아래 수치는 그 출력에서 다시 계산할 수 있습니다.

답변의 서식 결함
162 → 0
답변 32개에서 화면에 드러나는 결함 수. em-dash, 굵은 글씨, 표, 첫 줄의 헤더나 목록을 셉니다.
블라인드 판정
16쌍 중 12쌍
블라인드 판정에서 SimpleKorean 답변이 이긴 쌍. 3쌍은 비겼고 1쌍은 졌습니다.
문서의 린터 경고
0.71 → 0.17
문서 100어절당 린터 경고. 어절은 띄어쓰기로 나눈 단위입니다.
가장 긴 문장
18 → 15어절
문서 16개에서 가장 긴 문장. 엄격 모드는 13어절입니다.

문서와 답변은 claude-sonnet-5-5가 썼고 판정은 claude-opus-5-5가 했습니다.
판정 모델도 Claude라서 같은 계열에 유리한 편향이 있을 수 있습니다.

03 규칙

문장은 짧게, 답을 먼저 씁니다

긴 문장을 나누고, 불필요한 서식을 줄이고, 번역투를 고칩니다.

  • 답변

    첫 문장에 답을 씁니다

    고치기 전: 질문을 되풀이하는 머리말

  • 답변

    굵은 글씨와 표를 쓰지 않습니다

    고치기 전: 한 줄짜리 답을 둘러싼 서식

  • 답변

    em-dash를 쓰지 않습니다

    고치기 전: 반쯤 이어 붙인 생각

  • 문서

    절차문은 15어절, 설명문은 20어절 이하로 씁니다

    고치기 전: 끝없이 이어지는 만연체

  • 문서

    조건은 "-면"으로 명령 앞에 둡니다

    고치기 전: 명령 뒤에 붙어 늦게 읽히는 "단, ~경우"

  • 문서

    능동태와 단순 시제로 씁니다

    고치기 전: "되어지다", "~에 의해", "-고 있습니다"

  • 문서

    짐작과 권고 어미를 쓰지 않습니다

    고치기 전: "-ㄹ 수도 있습니다", "-것 같습니다"

  • 문서

    한 단어에는 한 뜻만 줍니다

    고치기 전: "확인", "검증", "점검"을 번갈아 쓰기

규칙은 항공 정비 문서에 쓰는 통제 영어 ASD-STE100에서 왔습니다. 전체 규칙은 SKILL.md에 있습니다.

04 표기

같은 용어는 같은 표기로 씁니다

외래어 표기법과 국립국어원 용례를 따릅니다. 정해진 표기가 없으면 프로젝트에서 쓸 표기를 정합니다.

  • 디렉터리디렉토리 아님
  • 메시지규범형
  • 애플리케이션규범형
  • 릴리스규범형
  • 셸규범형
  • 레포지토리관용형
  • 바디관용형
  • 칼럼관용형
  • 리팩터링공식 표기 없음
  • 반환값붙여 씀

회사 표기가 다르면 레포지토리 최상위의 .simple-korean.json으로 바꿀 수 있습니다.

05 설치

사용하는 도구에 맞춰 설치하세요

  • Claude Code

    스킬, 훅 세 개, 출력 스타일을 함께 설치합니다.

    claude plugin marketplace add say8425/SimpleKorean
claude plugin install simple-korean@simple-korean

  • Codex

    스킬과 세션 시작 훅을 설치합니다.

    codex plugin marketplace add say8425/SimpleKorean
codex plugin add simple-korean@simple-korean

  • 그 밖의 에이전트

    skills CLI로 스킬만 설치합니다.

    npx skills add say8425/SimpleKorean

  • Python

    Python 코드에서 답변 규칙과 린터를 사용합니다.

    pip install "simple-korean==1.2.0"

설치 없이 쓰려면 에이전트에게 레포지토리 주소를 주고 README를 따르라고 하세요.
