Korean from AI,
short and clear.

SimpleKorean is an agent skill. It makes AI write documents and replies in simple Korean.
It splits long sentences, removes translationese, and keeps the spelling of terms the same.
It takes ideas from SimpleEnglish and ASD-STE100.

03 Rules

Short sentences. The answer first.

The rules split long sentences, remove formatting that is not necessary, and fix translationese.

  • Reply

    Put the answer in the first sentence

    Stops: An opening that repeats the question

  • Reply

    Do not use bold text or tables

    Stops: Formatting around a one-line answer

  • Reply

    Do not use em-dashes

    Stops: Thoughts that are only half joined

  • Document

    Write procedures in 15 eojeol or fewer, and descriptions in 20 eojeol or fewer

    Stops: Long sentences that do not end

  • Document

    Put conditions before the command with "-면" (if)

    Stops: "단, ~경우" (however, in case of ~) after the command, which the reader sees too late

  • Document

    Use the active voice and simple tenses

    Stops: "되어지다" (double passive), "~에 의해" (by ~), "-고 있습니다" (is doing)

  • Document

    Do not use guessing or advice endings

    Stops: "-ㄹ 수도 있습니다" (may), "-것 같습니다" (seems)

  • Document

    Give one word only one meaning

    Stops: Switching between "확인", "검증", and "점검" (all mean "check")

The rules come from ASD-STE100, the controlled English for aircraft maintenance documents. The full rules are in SKILL.md.

04 Spelling

One term, one spelling

The skill follows the Korean loanword spelling rules and the examples of the National Institute of Korean Language. When no official spelling exists, the project chooses one.

  • 디렉터리not 디렉토리
  • 메시지standard form
  • 애플리케이션standard form
  • 릴리스standard form
  • 셸standard form
  • 레포지토리common form
  • 바디common form
  • 칼럼common form
  • 리팩터링no official spelling
  • 반환값written without a space

If your company uses a different spelling, change it in .simple-korean.json at the top of your repository.

05 Install

Install it for your tool

  • Claude Code

    Installs the skill, three hooks, and the output style.

    claude plugin marketplace add say8425/SimpleKorean
claude plugin install simple-korean@simple-korean

  • Codex

    Installs the skill and the session-start hook.

    codex plugin marketplace add say8425/SimpleKorean
codex plugin add simple-korean@simple-korean

  • Other agents

    Installs only the skill with the skills CLI.

    npx skills add say8425/SimpleKorean

  • Python

    Use the reply rules and the linter from Python code.

    pip install "simple-korean==1.2.0"

To use it without installing, give your agent the repository URL and tell it to follow the README.
