AIが書く韓国語を、
短く明確に。

SimpleKorean は、AI が文書と回答をやさしい韓国語で書くようにするエージェントスキルです。
長い文を分け、翻訳調を減らし、用語の表記をそろえます。
SimpleEnglish と ASD-STE100 から着想を得て作りました。

インストール GitHub で見る

03 ルール

文は短く、答えを先に書きます

長い文を分け、不要な書式を減らし、翻訳調を直します。

  • 回答

    最初の文に答えを書きます

    防ぐもの： 質問を繰り返す前置き

  • 回答

    太字と表を使いません

    防ぐもの： 1行の答えを囲む書式

  • 回答

    em-dash を使いません

    防ぐもの： 半分だけつながった考え

  • 文書

    手順文は15語節以下、説明文は20語節以下で書きます

    防ぐもの： どこまでも続く冗長な文

  • 文書

    条件は「-면」（〜なら）で命令の前に置きます

    防ぐもの： 命令の後ろに付いて遅れて読まれる「단, ~경우」（ただし〜の場合）

  • 文書

    能動態と単純な時制で書きます

    防ぐもの： 「되어지다」（二重受動）、「~에 의해」（〜によって）、「-고 있습니다」（〜しています）

  • 文書

    推測と勧めの語尾を使いません

    防ぐもの： 「-ㄹ 수도 있습니다」（〜かもしれません）、「-것 같습니다」（〜ようです）

  • 文書

    1つの語には1つの意味だけを与えます

    防ぐもの： 「확인」「검증」「점검」（どれも「確認」の意）を入れ替えて使うこと

ルールは、航空整備文書に使う統制英語 ASD-STE100 から来ています。ルールの全体は SKILL.md にあります。

04 表記

同じ用語は同じ表記で書きます

外来語表記法と国立国語院の用例に従います。決まった表記がない語は、プロジェクトで使う表記を決めます。

  • 디렉터리디렉토리ではない
  • 메시지規範形
  • 애플리케이션規範形
  • 릴리스規範形
  • 셸規範形
  • 레포지토리慣用形
  • 바디慣用形
  • 칼럼慣用形
  • 리팩터링公式の表記なし
  • 반환값続けて書く

会社の表記が違う場合は、リポジトリ最上位の .simple-korean.json で変えられます。

05 インストール

使うツールに合わせてインストールしてください

  • Claude Code

    スキル、フック3つ、出力スタイルをまとめてインストールします。

    claude plugin marketplace add say8425/SimpleKorean
claude plugin install simple-korean@simple-korean

  • Codex

    スキルとセッション開始フックをインストールします。

    codex plugin marketplace add say8425/SimpleKorean
codex plugin add simple-korean@simple-korean

  • そのほかのエージェント

    skills CLI でスキルだけをインストールします。

    npx skills add say8425/SimpleKorean

  • Python

    Python のコードから回答ルールとリンターを使います。

    pip install "simple-korean==1.2.0"

インストールせずに使うには、エージェントにリポジトリの URL を渡し、README に従うよう指示してください。
