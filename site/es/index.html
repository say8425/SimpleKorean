03 Reglas

Oraciones cortas. La respuesta primero.

Las reglas dividen las oraciones largas, quitan el formato innecesario y corrigen los calcos de traducción.

  • Respuesta

    Ponga la respuesta en la primera oración

    Evita: Una introducción que repite la pregunta

  • Respuesta

    No use negrita ni tablas

    Evita: Formato alrededor de una respuesta de una línea

  • Respuesta

    No use em-dash

    Evita: Ideas unidas solo a medias

  • Documento

    Escriba los procedimientos en 15 eojeol o menos, y las descripciones en 20 eojeol o menos

    Evita: Oraciones largas que no terminan

  • Documento

    Ponga las condiciones antes de la orden con «-면» (si)

    Evita: «단, ~경우» (sin embargo, en caso de ~) después de la orden, que el lector ve demasiado tarde

  • Documento

    Use la voz activa y tiempos simples

    Evita: «되어지다» (doble pasiva), «~에 의해» (por ~), «-고 있습니다» (está haciendo)

  • Documento

    No use terminaciones de suposición ni de consejo

    Evita: «-ㄹ 수도 있습니다» (puede que), «-것 같습니다» (parece)

  • Documento

    Dé a cada palabra un solo significado

    Evita: Alternar «확인», «검증» y «점검» (todas significan «comprobar»)

Las reglas vienen de ASD-STE100, el inglés controlado de los documentos de mantenimiento aeronáutico. Las reglas completas están en SKILL.md.

04 Escritura

Un término, una escritura

La skill sigue las normas coreanas de transcripción de préstamos y los ejemplos del Instituto Nacional de la Lengua Coreana. Si no hay una escritura oficial, el proyecto elige una.

05 Instalación

Instálela según su herramienta

  • Claude Code

    Instala la skill, tres hooks y el estilo de salida.

    claude plugin marketplace add say8425/SimpleKorean
claude plugin install simple-korean@simple-korean

  • Codex

    Instala la skill y el hook de inicio de sesión.

    codex plugin marketplace add say8425/SimpleKorean
codex plugin add simple-korean@simple-korean

  • Otros agentes

    Instala solo la skill con la CLI de skills.

    npx skills add say8425/SimpleKorean

  • Python

    Use las reglas de respuesta y el linter desde código Python.

    pip install "simple-korean==1.2.0"

Para usarla sin instalar, dé a su agente la URL del repositorio y pídale que siga el README.
