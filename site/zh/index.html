让 AI 写的韩语
简短清楚。

SimpleKorean 是一个智能体技能，让 AI 用简单的韩语写文档和回答。
它拆分长句，减少翻译腔，并统一术语的写法。
它的灵感来自 SimpleEnglish 和 ASD-STE100。

162 → 0
32 个回答中读者能看到的缺陷数。统计 em-dash、粗体、表格，以及第一行的标题或列表。

在不知道哪个是技能回答的评判中，16 组里 SimpleKorean 回答胜出的组数。3 组打平，1 组落败。
文档的检查器警告

03 规则

句子要短，先写答案

拆分长句，减少不必要的格式，修正翻译腔。

  • 回答

    在第一句写出答案

    防止： 重复问题的开场白

  • 回答

    不用粗体和表格

    防止： 包在一行答案外面的格式

  • 回答

    不用 em-dash

    防止： 只连了一半的想法

  • 文档

    操作句不超过 15 个语节，说明句不超过 20 个语节

    防止： 没完没了的长句

  • 文档

    用“-면”（如果）把条件放在命令前面

    防止： 放在命令后面、读者读到时已太晚的“단, ~경우”（但是，在~的情况下）

  • 文档

    使用主动语态和简单时态

    防止： “되어지다”（双重被动）、“~에 의해”（由~）、“-고 있습니다”（正在~）

  • 文档

    不用猜测和建议语尾

    防止： “-ㄹ 수도 있습니다”（可能）、“-것 같습니다”（好像）

  • 文档

    一个词只表示一个意思

    防止： 交替使用“확인”“검증”“점검”（都表示“检查”）

这些规则来自航空维修文档使用的受控英语 ASD-STE100。完整规则见 SKILL.md。

04 写法

同一个术语用同一种写法

遵循韩语外来语标记法和国立国语院的用例。没有规定写法的词，由项目决定使用的写法。

  • 디렉터리不写作 디렉토리
  • 메시지规范形式
  • 애플리케이션规范形式
  • 릴리스规范形式
  • 셸规范形式
  • 레포지토리惯用形式
  • 바디惯用形式
  • 칼럼惯用形式
  • 리팩터링没有官方写法
  • 반환값连写

如果公司的写法不同，可以在仓库根目录的 .simple-korean.json 中修改。

05 安装

按你使用的工具安装

  • Claude Code

    一起安装技能、三个钩子和输出样式。

    claude plugin marketplace add say8425/SimpleKorean
claude plugin install simple-korean@simple-korean

  • Codex

    安装技能和会话启动钩子。

    codex plugin marketplace add say8425/SimpleKorean
codex plugin add simple-korean@simple-korean

  • 其他智能体

    用 skills CLI 只安装技能。

    npx skills add say8425/SimpleKorean

  • Python

    在 Python 代码中使用回答规则和检查器。

    pip install "simple-korean==1.2.0"

如果不安装就使用，请把仓库地址交给智能体，并让它按照 README 操作。
